# 🎭 Face Detection using OpenCV

## 📌 Overview
This project detects human faces in real-time using computer vision techniques.  
It uses OpenCV and Haar Cascade classifier for face detection.

---

## ⚙️ Technologies Used
- Python 🐍
- OpenCV
- NumPy

---

## 🚀 Features
- Real-time face detection using webcam
- Detects multiple faces
- Uses Haar Cascade classifier

---

## ▶️ How to Run

```bash
pip install opencv-python numpy
python face_detect.py
```
